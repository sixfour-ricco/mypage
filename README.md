# Sixfour / RICCO デジタル会員証（マイページ）

LINE Mini App（LIFF）で動作する会員証マイページ。

## ⚠️ セキュリティ注意（重要）

- **このリポジトリは public です。世界中の誰でも閲覧できます。**
- 以下は【絶対に】このリポジトリに置かないこと：
  - 顧客・会員の個人情報（氏名／電話／生年月日／購入履歴 等）
  - CSV・Excel などの会員データファイル
  - APIキー・アクセストークン・チャネルシークレット・合言葉
  - GASのサーバー側コード（合言葉 STAFF_PASSWORD を含むため）
- 顧客データは GitHub ではなく、アクセス制限付きの別環境（スプレッドシート／Airtable 等）で管理する。
- 認証は GAS 側の LINE IDトークン検証（verifyIdToken_）で担保。バックエンドURLが露出しても未認証は弾かれる。

## ファイル構成
- `index.html` … LIFF入口（LINEログイン → マイページ表示）
- `demo.html` … 会員証マイページ本体（9タブ構成のデモ／表示ロジック）
